Fluorescence Detection System

Embedded Systems Optics Python Custom PCB
Project photo — replace with your image

Overview

Designed and optimized a fluorescence-based detection system for a life science client, with the goal of enabling quantitative diagnostic readings in a compact, portable form factor.

The system integrates off-the-shelf evaluation boards with custom analog front-end circuitry and purpose-built firmware to achieve the signal-to-noise ratio required for clinical-grade measurements.

The problem

Existing benchtop fluorescence readers were too large and expensive for point-of-care deployment. The client needed a solution that could be manufactured at low cost without sacrificing measurement fidelity.

My approach

I started with a breadboard prototype using an off-the-shelf photodiode amplifier module to characterize the optical path and validate the measurement concept. Once the signal chain was understood, I designed a custom PCB integrating the LED driver, transimpedance amplifier, and microcontroller onto a single board.

  • Characterized LED excitation spectrum vs. fluorophore absorption
  • Designed low-noise TIA circuit with programmable gain
  • Wrote firmware for automated calibration and data logging
  • Built Python data pipeline for post-processing and visualization

Outcome

The final system achieved the target detection limit at under one-fifth the cost of the incumbent benchtop solution, and was compact enough to be carried in a field kit.
